# いろいろ図鑑

写真をとって、色や向きを変えて、名前・レア度・せつめいをつけて、じぶんだけの図鑑にしまうアプリ(PWA)。

- 図鑑は何冊でも作れる。図鑑ごとに なまえ・ひょうしの色・ページの色・もよう・写真のわく を変えられる
- 色はパレット(12色)か、すきな色をえらべる。こさも変えられる
- 向きは 左右90度・うらがえし・さかさま
- 写真はスマホの中(IndexedDB)だけに保存。バックアップはファイルに書き出し/読みこみ
- 公開: GitHub Pages(main/docs)

テスト: `node tools/serve.js` のあと `node tools/flowtest.js`(SE2 375×553 / sense9 412×760 / 430×740 で通しプレイ)
